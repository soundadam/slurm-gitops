# 节点清单

普查于 2026-09-27，从 elon 经 `114.212.224.242:100NN` 逐台 SSH 读取。
硬件和驱动会变；接入 Slurm 时以节点上 `slurmd -C` 的输出为准，不以这张表为准。

## 网络与共享服务

- 节点都在 `192.168.50.0/24`，默认网关 `192.168.50.1`。
- 对外只有 NAT：`114.212.224.242` 的 `100NN` 端口转发到 gNN 的 22；节点出网也显示为这个地址。
  g12–g14 走另一个出口 `210.28.136.239`，从 elon 连不上。
- 用户与组来自 NIS（`nsswitch.conf` 的 passwd 行含 `nis`），home 是
  `192.168.50.229:/home/nis` 的 NFS。同一个用户在所有节点上 uid 相同。
- `192.168.50.229` 与 `192.168.50.1` 是什么设备、谁管，未确认。
