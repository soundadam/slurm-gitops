# 采购需求单

[方案](plan.md)要买的全部东西，按网络、热存储、冷存储、控制节点、供电分块。每一项写规格要求、数量，以及两种买法的价格：

- **全新：** 行货，有保修。
- **现货：** 二手、拆机、库存尾货。便宜，但没有保修或只有商家短保，到货要自己验。
  实验室体量不大，有一定容错余地，所以哪些部件能买现货、哪些不能，逐项写在「说明」里。

**价格只看量级。** 这是 2026 年 9 月国内市场的粗略区间，下单前要逐项询价。企业级固态和服务器内存今年涨了一倍以上、还在波动，机械盘也在涨。

**可以省的地方：**
- **数据盘起步买 6 块，** 省 ¥1.6–3 万。代价是装不下全部 90 天内读过的数据，要成员先挑，见[热存储「装多少」](hot-storage.md#装多少)。
- **数据盘买拆机的。** raidz2 能扛同时坏两块，冷存储上每天还有一份，所以对热存储的数据盘可以容忍一些风险。拆机盘要逐块看 SMART 里的剩余寿命。

## 买之前要确认

- [ ] 机柜里放不放得下 2U、4U 各一台，再加两台 1U；供电能不能再带两台存储
- [ ] g18（H3C R5300 G6）、g19（PUERSAI PGA443-D08L）插满 GPU 以后，还有没有空闲的 PCIe 或 OCP 插槽
- [ ] g2、g4、g5、g6 有没有空闲的 PCIe x1 插槽
- [ ] 现有两台管理机的硬件，能不能拿来当控制节点
- [ ] 利旧的三块企业盘要在拔之前检查，清单见[冷存储](cold-storage.md#现有的盘能拿来用多少)
