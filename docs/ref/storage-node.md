# 冷存储节点：利旧与采购

这份文档讲[档 1](tiers.md) 的冷存储 st0 怎么配。利旧起步和全新 16 盘两种配置都列在这里，还没有定用哪一种。

- 现有每块机械盘的型号、系列、记录方式和用量，见 [inventory「机械盘」](inventory.md#机械盘)。
- 冷存储要复制多少数据，见 [inventory「存储资源」](inventory.md#存储资源)；其中多少是一年以上没动过的，见 [inventory「数据的年龄」](inventory.md#数据的年龄)。

## 现有的盘能拿来用多少

**进冷存储池只收一种盘：企业级、CMR、容量和新盘相同。** 不符合这三条的，不进池。

| 不收的盘 | 为什么 |
| --- | --- |
| SMR 盘 | 持续写入一段时间后会停顿几分钟，坏盘后重建也要拖好几倍的时间 |
| 桌面级、监控级的小盘 | 设计上不是 7×24 小时在阵列里跑的；1–4T 的盘占一个盘位，只带来很少的容量 |
| 容量比新盘小的盘 | raidz 里每块盘只按组里最小的那块算，小盘会把整组拉低 |

按这三条过一遍现有的 14 块机械盘，结论如下。

| 盘 | 用法 |
| --- | --- |
| **g18 的 24T HC580** | **进冷存储主池。** 新盘买同一型号 `WUH722424ALE6L4`，这样容量一个扇区都不差，g18 这块才能加进同一组 raidz2 |
| **g5、g19 的 16T HC550**，共两块 | **不进主池，改作离线备份盘。** 用法见下面「RAID 不是备份」 |
| 其余 11 块（1–4T 的桌面盘、监控盘、SMR 盘） | 不进池。本地盘清空以后，留在原节点当慢速的本地盘，或者直接退役 |
| 各节点的 SATA 固态、NVMe | 不进池，留在原节点做 `/scratch` |

g18 那块 3.84T 的 PM9A3 是带掉电保护的企业级 U.2，正适合给 g18 当训练缓存。g18 真正值得拔出来的只有那块 24T 机械盘，其余的盘留在原机更有用。

**拔盘之前要确认：**

- [ ] 管理员用 `smartctl` 查这三块企业盘的健康情况：通电时长、重映射扇区、待处理扇区、CRC 错误
- [ ] 用序列号在 WD 官网查保修。这两个系列都是五年保
- [ ] g18 的盘位是不是前置热插拔；g5 是台式机，拔盘要停机开机箱

## 池怎么排

**主池用一组 raidz2，从 6 块新盘起步，之后一块一块往上加盘。**
这要靠 OpenZFS 2.3 开始支持的 raidz 扩容（`zpool attach` 到 raidz 组上）。发行版里 Ubuntu 26.04 和 TrueNAS SCALE 24.10 以后都带这个版本。

| 阶段 | 盘 | 数据盘 | 可用约 | 八成水位 | 装得下 |
| --- | --- | --- | --- | --- | --- |
| 起步 | 6 块新 24T | 4 | 90T | 72T | 一年以上没修改过的数据，约 62T |
| 加入 g18 的 HC580 | 7 块 | 5 | 110T | 88T | |
| 之后每加一块新盘 | +1 | +1 | +22T | +18T | |
| 装下现在的全部数据 | 9 块新盘 + g18 那块 | 8 | 176T | 141T | 各节点 `/data*` 加上 `/home/nis`，约 133T |
| 一组 raidz2 的上限 | 11 块新盘 + g18 那块 | 10 | 220T | 176T | 上一行再加一年的新写入就装不下 |

「装得下」一栏的数怎么来的：
- **按实际占的盘算，再加 5%。** 数据量取 [inventory](inventory.md#数据的年龄) 的实测。raidz2 按 4K 扇区分配，
  每个文件末尾不满一条的部分也要配两份校验、再补齐。平均几百 KB 的文件，比按宽度算的多占百分之几，
  这里按 5% 取整，WAV 基本压缩不动，不算压缩。
- **g12–g14 没有采集到，不在里面。**
- **增长：** 最近一年修改过的数据见 inventory「数据的年龄」前两行。复制文件时没带 `-p` 的，修改时间是复制那天，
  所以它是一年新写入量的上限。按它算，冷存储一年要加两三块盘，一组 12 块的上限大约一年就到。

**扩容有几个代价，要事先知道：**
- **只能一次加一块盘。** 每加一块，都要把已有的数据重新排布一遍，满盘时要跑好几天。
- **扩容前写入的数据，仍按原来的「数据盘比校验盘」比例存放。** 这部分数据重写以后，才能用上新的比例。
  所以表里「可用」一栏是估算，实际会比按宽度算出来的少一点。
- **一组 raidz2 放到 10–12 块盘为止。** 再多的话，重建一块 24T 盘时会有太多盘一起参与，时间拉长，风险也跟着升。
  要再扩，就另起一组。

**和全新 16 块盘方案的比较：**
- 起步只要 6 块新盘，而不是 16 块。
- 容量可以跟着成员清理的结果来加。清理以后剩下的不超过 88T，6 块新盘加 g18 那块就装得下；剩得多，就一块一块补。
- 代价有两个：冷存储的写入速度低一些（见 [freeze-estimate](freeze-estimate.md)）；数据要分两批冻结：起步的池子装不下全部数据，而 g18 那块 24T 盘本身装着数据，要先把它上面的数据冻结到池里，才能腾出来并进池。

**元数据盘（special vdev）：** 可选，用来放元数据。
- **什么时候需要：** 按条切好的 wav 让各节点的 `/data*` 有上亿个文件（[inventory「数据的年龄」](inventory.md#数据的年龄)），列目录、跑 rsync 都要反复查元数据。把元数据放在固态盘上，这些操作会快得多。
- **什么时候加：** 最好建池时就加上。事后再加的话，已经写进去的元数据还留在机械盘上。
- **用什么盘：** 两块带掉电保护的企业级 SATA 固态，做镜像。这组坏了，整个池就丢了，所以必须镜像，也不能用消费级盘。

## RAID 不是备份

raidz2 解决的是「同时坏两块盘，数据还在、服务不停」。下面这些它都挡不住：

- 误删、误覆盖。快照能挡住这一种，但快照和数据在同一个池里。
- 整台机器坏掉：电源烧了，背板或者 HBA 出故障把池写坏了。
- 机房出事：断电、进水、失火、被盗。

**备份的意思是另一份独立的副本。** 要备份的只有不可再生的数据，也就是原始录音和人工标注。能从原料重新生成的东西不用备份。

**不花钱的做法：** 把腾出来的两块 16T HC550 当离线备份盘。
- 每块盘建一个单盘 ZFS 池，用 `zfs send` 从主池把不可再生的数据复制过去。
- 平时一块放在另一个房间，不通电；另一块每月接上来，增量同步一次。两块轮换着用。
- 擦掉各节点的本地盘之前，不可再生的数据要在冷存储之外有这第二份。只要它不超过 16T，这两块盘就够了；
  超过 16T，就要上[档 3](tiers.md) 的异地冷存储，或者对象存储。

## 整机清单

| 部件 | 要求 | 为什么 |
| --- | --- | --- |
| 机箱 | 4U，24 个 3.5 英寸热插拔盘位，背板带 SAS3 扩展器（兼容 SATA 盘） | 按表里的阶段加到十来块盘，还剩一半盘位 |
| 盘控制器 | HBA，LSI 9300-8i、9400-8i 或同级，刷 IT 模式 | ZFS 要直接看到每一块盘。**不要用 RAID 卡**：硬 RAID 把盘藏在后面，ZFS 就没法校验和修复 |
| 主板和 CPU | 单路，8–16 核，支持 ECC；上一代至强或 EPYC 7002 都够 | 压缩和 rsync 的加密都要吃 CPU，但冷存储不需要强 CPU |
| 内存 | 64–128 GB ECC | ZFS 拿内存当读缓存。冷存储读得少，64 GB 起步就够。不开去重 |
| 系统盘 | 两块小固态做镜像 | 系统盘坏了不影响数据池，但会停机 |
| 网卡 | 双口 25G SFP28（ConnectX-4 Lx 或同级） | 接档 1 的汇聚交换机，到档 2 再接核心交换机 |
| 电源 | 冗余电源，800W 以上 | 24 块机械盘同时起转会有电流尖峰。HBA 和背板要支持分批起转 |
| 备用盘 | 一块同型号的 24T 放在柜子里 | 坏盘当天就能换上，不用等采购 |

**系统，待定：**
- **TrueNAS SCALE：** 快照、复制、定期 scrub、SMART 告警都能在网页上点出来，适合一个人运维。
- **Ubuntu 26.04 加 ZFS：** 和计算节点用同一套 Ansible 管，但上面这些都要自己配。

## 两种配置的估价

价格是 2026 年国内市场的粗略区间，只看量级。24T 企业盘按每块 ¥3,500–4,500 算。

| 项 | 利旧起步 | 全新 16 盘 |
| --- | --- | --- |
| 机箱、主板、CPU、内存 | ¥1–3 万（二手准系统低，全新整机高） | ¥2.5–4 万 |
| 新数据盘 | 6 块 ¥2.1–2.7 万；清理不够再加 2 块 ¥0.7–0.9 万 | 16 块 ¥5.6–7.2 万 |
| HBA、网卡、系统盘 | ¥0.2–0.4 万 | ¥0.2–0.4 万 |
| 元数据盘（可选） | ¥0.2–0.4 万 | ¥0.3–0.6 万 |
| 备用盘 | ¥0.35–0.45 万 | ¥0.35–0.45 万 |
| **合计** | **约 ¥3.5–7 万** | **约 ¥9–12.5 万** |

二手准系统便宜，但没有保修，背板和电源都要看清成色。数据盘不建议买拆机盘或翻新盘。
